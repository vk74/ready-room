Disk Status

Disk usage for the system and data volumes. Warnings appear when usage exceeds 85%. Critical alerts appear above 95%.

Critical: Disk space is critically low. Free up space immediately to prevent service interruption.
Warning: Disk space is running low. Consider freeing up space or expanding the disk.

Full Backup

          

            Create a complete backup of all application components: container images, database,
            file storage (fs_data), state store (state_data),
            environment configuration, TLS certificates, JWT secrets, and installation scripts.
            The backup set is self-contained and supports two restore scenarios:
            restore on a new server (fresh install with auto-setup of system prerequisites),
            or restore over the current installation (wipes the current installation and replaces it with the backup).
            A restore instructions file (README-RESTORE-STEP-BY-STEP.md) with step-by-step
            guidance for both scenarios will be created alongside the backup.
